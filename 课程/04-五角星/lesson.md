# 第 4 课：画一个五角星

## 先确认三件事

老师会问你三次，每次只问一个：

1. **画什么**：五角星、圆，还是写字？
2. **多大**：半径 12、21，还是 30？（半径 30 会顶到屏幕边）
3. **去哪**：先在电脑上看，还是送到地震仪？

你选完，老师会把它翻译成一句话。听不懂就问，那才是这节课真正的内容。

## 先猜一猜

屏幕上有 256 列、64 行。要在正中间画一个五角星，你觉得**最少要告诉电脑几个点**？

（先说出你的答案，再往下看。）

## 一个类比

画五角星就像**放风筝**：先在五个位置插好杆子，再用线把它们连起来。
杆子的位置是"顶点"，线的连法是"顺序"。两件事都对了，星星才出来。

## 五个顶点

屏幕中心是 (128, 32)。五个顶点绕中心均匀分布，每隔 72° 一个：

```python
import math
for i in range(5):
    x = 128 + 21 * math.cos(math.radians(-90 + 72 * i))
    y = 32 + 21 * math.sin(math.radians(-90 + 72 * i))
    print(round(x), round(y))
```

`21` 是半径，`-90` 让第一个顶点朝正上方。

## 关键的一步：隔一个连

按 0→1→2→3→4 连起来，你得到的是**五边形**。要连成星星，必须隔一个：
**0→2→4→1→3→0**。

这一步没有任何公式，是"连法"决定的。改一个数字就能看到区别。

## 你来试试

在 `demo/star.py` 里改一个数，然后重新跑：

1. 把 `r=21` 改成 `r=30` —— 星星变大。
2. 把 `r=21` 改成 `r=10` —— 星星变小。
3. 把 `board.star()` 换成 `board.star(r=21)` 再改 `cx` —— 星星左右移动。

## 送到真机

```sh
python3 star.py            # 先看电脑上的图
python3 star.py --device   # 满意了再送
```

真机上星星会叠在波形上面。想只看星星：

```python
pen.overlay(False)
```

## 一句话带走

**图形 = 顶点 + 连法。** 顶点决定"在哪"，连法决定"是什么形状"。
