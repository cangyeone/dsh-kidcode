## 一枚印章

刻一枚印章只刻一次，想盖三次就按三次。

函数就是这枚印章：把一串动作打包，起个名字，之后叫名字就行。

```python
def yinzhang(pen, x):        # 刻印章：只写这一次
    pen.text(x, 26, "震")

for x in (88, 128, 168):     # 盖三次，只换位置
    yinzhang(pen, x)
```

`x` 是印章的把手：转一下，它就盖到别处。印章上的字不变。
